## Projetos próprios

### [Ranking Strava ↗](https://github.com/pedroribeirodev/ranking-strava)

Ranking de atividades de clubes do Strava, com painel de acompanhamento, atividades recentes e atualização de pontuações. Integra a API do Strava e armazena os dados no Redis.

`Next.js` `TypeScript` `Tailwind CSS` `Upstash Redis`

### [BioBora ↗](https://github.com/pedroribeirodev/biobora/tree/development)

Plataforma de link na bio **em desenvolvimento**, com autenticação e modelagem de páginas e links. O código em construção está na branch `development`.

`Next.js` `TypeScript` `Auth.js` `Prisma` `PostgreSQL`

## IA aplicada

Experimentos da minha trilha de estudos em IA, conectando modelos de linguagem a ferramentas e dados.

### [ImobiBot ↗](https://github.com/pedroribeirodev/imobibot)

Agente que busca, compara e gera relatórios de imóveis a partir de perguntas em linguagem natural. Explora chamadas de ferramentas, acompanhamento de custo e condições de parada, usando uma base fictícia.

`TypeScript` `Gemini` `SQLite` `Agents`

### [GarçomIA ↗](https://github.com/pedroribeirodev/garcomia)

Servidor MCP que conecta o Claude Desktop aos dados de um restaurante fictício. Expõe seis ferramentas para consultar estoque, vendas, faturamento, cardápio e reservas.

`TypeScript` `MCP` `SQLite` `Claude Desktop`
